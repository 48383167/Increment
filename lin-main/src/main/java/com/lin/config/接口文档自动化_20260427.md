# 接口文档自动化 (Knife4j)

**版本**: 2026-04-27
**所属模块**: `lin-main`

## 1. 为什么需要自动生成接口文档？

以前开发完接口后，还要手动在 YApi、Postman 或 Word 文档里写接口说明，不仅费时费力，还极容易出现代码改了但文档没更新的尴尬情况。引入接口文档自动化工具可以彻底解决这个痛点：**代码即文档**。

## 2. 结构构造

我们引入了 `knife4j-openapi3-jakarta-spring-boot-starter`，这是在 Spring Boot 3 环境下整合 Swagger3 (OpenAPI 3) 和 Knife4j 漂亮 UI 的最佳实践。

### 2.1 全局配置 (`SwaggerConfig.java`)
使用 `@Configuration` 声明配置类，通过 `customOpenAPI()` 注入全局的文档标题、版本号和描述。

### 2.2 接口与入参注解
为了让生成的文档不仅有 URL，还有具体的中文释义，我们使用以下注解：
- **`@Tag`**：用于 Controller 类上，表示模块名称（如 `@Tag(name = "测试模块")`）。
- **`@Operation`**：用于接口方法上，描述接口的具体功能（如 `@Operation(summary = "测试成功返回")`）。
- **`@Schema`**：用于 DTO 类和字段上，提供中文描述和示例值（如 `@Schema(description = "用户名", example = "admin")`）。

## 3. 作用与优势

- **零维护成本**：只要你更新了 Java 代码和注解，刷新网页，最新的接口文档就自动生成了。
- **在线调试**：Knife4j 提供的界面（`/doc.html`）不仅能看文档，还能直接填入参数发起测试请求，直接替代了本地的 Postman。
- **一键导出**：如果需要给第三方提供文档，可以直接在 Knife4j 界面上将文档导出为 Markdown、HTML 甚至是离线文档。
